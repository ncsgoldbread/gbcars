# GB CarSys 2.0 — ระบบบริหารการใช้รถ (PWA)

เวอร์ชันใหม่ของระบบ CarSYS 1.13 (Yii 1.1) เขียนใหม่ด้วย **HTML + CSS + JavaScript (ES Modules) + PHP 8 + MySQL/MariaDB**
ใช้งานได้ทั้งคอมพิวเตอร์และมือถือ และติดตั้งเป็นแอป (PWA) ได้ — ไม่ต้อง build ไม่มี framework ภายนอก

## ความสามารถ

| หมวด | รายละเอียด |
|---|---|
| แดชบอร์ด | รถพร้อมใช้, การใช้รถวันนี้, งานรออนุมัติ, แจ้งเตือน ภาษี/พ.ร.บ./ประกัน ใกล้หมดอายุ, กราฟ 6 เดือน |
| ปฏิทินการใช้รถ | มุมมองรายเดือน กรองตามรถ คลิกวันเพื่อดูรายการ/จองต่อ |
| จองใช้รถ | เลือกช่วงเวลา → ระบบแสดงรถว่าง (พร้อมรูป) → กรอกรายละเอียด ป้องกันจองซ้อนทั้งรถและคนขับ |
| อนุมัติ | ผู้อนุมัติประจำแผนก อนุมัติ/ไม่อนุมัติ มอบหมายคนขับ, ส่งคืนรถ → รับคืนรถ (บันทึกค่าเสียหาย) |
| บันทึกการใช้รถ | เลขไมล์ น้ำมัน ค่าใช้จ่าย รายรับ สร้างจากใบจองได้ในคลิกเดียว |
| ข้อมูลรถ | รูปรถ 5 รูป, ไฟล์เอกสารแนบ, วันหมดอายุเอกสาร |
| ซ่อมบำรุง / ประกันภัย / ต่อทะเบียน / พ.ร.บ. / ค่างวด | รันเลขเอกสารอัตโนมัติ (เช่น `REV69110001`) ต่อประกัน/ภาษี/พ.ร.บ. แล้ววันหมดอายุของรถอัปเดตให้อัตโนมัติ |
| รายงาน 12 แบบ | สรุปตามแผนก/หน่วยงาน/รถ/คนขับ/เดือน พิมพ์ A4 และส่งออก Excel (CSV ภาษาไทย) |
| PWA | ติดตั้งบนมือถือ/เดสก์ท็อป, เปิดแบบออฟไลน์ได้ (แสดงข้อมูลล่าสุดที่เคยโหลด), โหมดมืด |
| ความปลอดภัย | รหัสผ่าน bcrypt (รหัสเดิม md5 ใช้ได้และอัปเกรดอัตโนมัติเมื่อเข้าสู่ระบบ), CSRF token, จำกัดการเดารหัสผ่าน, ไฟล์แนบต้องล็อกอินก่อนเปิด, SQL แบบ prepared statements |

## ติดตั้ง (XAMPP / AppServ / โฮสติ้ง PHP ทั่วไป)

ต้องการ PHP 8.1 ขึ้นไป (extension `pdo_mysql`) และ MySQL 5.7+ หรือ MariaDB 10.3+

1. คัดลอกโฟลเดอร์นี้ไปไว้ในเว็บเซิร์ฟเวอร์ เช่น `C:\xampp\htdocs\gbcars`
2. คัดลอก `config/config.sample.php` เป็น `config/config.php` แล้วแก้ชื่อฐานข้อมูล/ผู้ใช้/รหัสผ่าน
3. สร้างฐานข้อมูล (เลือกอย่างใดอย่างหนึ่ง)
   - **ย้ายข้อมูลจากระบบเก่า** (แนะนำ):
     ```bash
     php database/migrate.php --dump=F:/Project/gbcarsys/admin_carsys.sql --files=F:/Project/gbcarsys/fileupload
     ```
     สคริปต์จะสร้างฐานข้อมูล นำเข้าข้อมูลทุกตาราง แปลงวันที่ `0000-00-00` เป็นค่าว่าง และคัดลอกรูป/ไฟล์แนบไปที่ `uploads/`
   - **เริ่มใหม่ว่างเปล่า**: สร้างฐานข้อมูล `gbcars` ใน phpMyAdmin แล้ว Import ไฟล์ `database/schema.sql`
     จากนั้นเพิ่มผู้ดูแลระบบคนแรกใน phpMyAdmin (ตาราง `tb_user`, `member_type = 1`, รหัสผ่านสร้างด้วย `php -r "echo password_hash('รหัสผ่าน', PASSWORD_DEFAULT);"`)
4. เปิด `http://localhost/gbcars/` และเข้าสู่ระบบด้วยชื่อผู้ใช้/รหัสผ่านเดิม

> PWA (ติดตั้งเป็นแอป/ออฟไลน์) ต้องเปิดผ่าน **HTTPS** หรือ `localhost`

### ทดสอบเร็วด้วย PHP built-in server
```bash
php -S localhost:8090 -t .
```

## โครงสร้าง

```
index.html               หน้าเดียว (SPA) + โหลด assets/js/app.js
manifest.webmanifest     ข้อมูลแอป PWA
sw.js                    Service Worker (แคชหน้าแอป, ข้อมูล API ล่าสุด, รูป)
assets/css/app.css       ดีไซน์ทั้งหมด (สว่าง/มืด, มือถือ, หน้าพิมพ์)
assets/js/core.js        ตัวช่วย: API, template, ฟอร์ม, รูปแบบวันที่ไทย
assets/js/views/*.js     หน้าจอ: dashboard, calendar, booking, crud, reports, profile
api/index.php            REST API router
api/lib/resources.php    นิยามตาราง/ฟิลด์ทั้งหมด (ใช้ทั้งฝั่ง API และสร้างฟอร์มหน้าเว็บ)
api/lib/booking.php      ขั้นตอนจอง-อนุมัติ-คืนรถ
api/lib/reports.php      แดชบอร์ดและรายงาน
database/schema.sql      โครงสร้างฐานข้อมูล (ชื่อตาราง/คอลัมน์เข้ากันได้กับระบบเดิม)
database/migrate.php     ย้ายข้อมูลจาก CarSYS 1.13
uploads/                 รูปและไฟล์แนบ (ไม่อยู่ใน git)
```

### เพิ่มฟิลด์หรือหน้าจัดการข้อมูลใหม่
แก้ที่ `api/lib/resources.php` ที่เดียว (เพิ่มคอลัมน์ในฐานข้อมูลด้วย) — หน้ารายการ ฟอร์ม และการตรวจสอบข้อมูลจะสร้างให้อัตโนมัติ

### ออกเวอร์ชันใหม่
เปลี่ยนค่า `VERSION` ใน `sw.js` ทุกครั้งที่อัปเดตไฟล์หน้าเว็บ เพื่อให้เครื่องผู้ใช้โหลดไฟล์ใหม่

## สถานะการจอง (เหมือนระบบเดิม)
`0` รออนุมัติ → `1` เปิดอ่านแล้ว → `2` อนุมัติ / `3` ไม่อนุมัติ · `4` ยกเลิก · `5` ส่งคืนรถแล้ว → `6` รับคืนรถแล้ว

## ข้อมูลส่วนบุคคล
Repository นี้เป็นสาธารณะ — **ห้าม commit** ไฟล์ `config/config.php`, ไฟล์ dump `.sql` ของฐานข้อมูลจริง หรือโฟลเดอร์ `uploads/` (กำหนดไว้ใน `.gitignore` แล้ว)
